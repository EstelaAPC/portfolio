01 / FINANÇAS PESSOAIS · AWS CLOUD

FinanceFlow

Plataforma de gestão financeira pessoal e análise de dados, desenvolvida com Angular e .NET. A arquitetura cloud-native utiliza AWS Lambda para o backend serverless e Amazon DynamoDB como banco de dados, integrado pelo AWS SDK — com a aplicação publicada na AWS.

AWS Lambda Amazon DynamoDB AWS SDK AWS Amplify Angular TypeScript ASP.NET Core C#

02 / TCC · MONITORAMENTO DE REDES

NetGuard

Plataforma proativa de monitoramento e rastreabilidade de incidentes em redes corporativas. O sistema coleta métricas via ICMP, TCP e SNMP, apresenta dados em dashboards e ajuda a investigar incidentes com apoio de IA.

Python FastAPI React PostgreSQL TimescaleDB Grafana Docker ICMP · TCP · SNMP IA

Biblioteca de interface independente de framework, construída com Web Components, Lit e TypeScript. O Nexora oferece componentes reutilizáveis, Shadow DOM, design tokens e propriedades CSS para criar interfaces consistentes e acessíveis em diferentes aplicações.
